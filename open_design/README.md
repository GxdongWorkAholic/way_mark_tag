# WayMarkTag · 常用网站管理（新标签页原型）

一个极简新标签页：大号时钟 + 多引擎搜索 + 可翻页的常用网站面板，黑白双主题，无账号、无云同步，数据只存本机，支持 JSON 导出/导入。

当前是纯静态单文件页面（`index.html`），不是已打包的浏览器扩展。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 全部内容：结构、样式、脚本内联，双击即可运行 |
| `README.md` | 本文档 |

## 打开方式

1. 直接双击 `index.html`，或用浏览器打开该文件。
2. 想当作起始页使用：浏览器设置里把「主页 / 启动页」指向这个文件的本地地址（或后续封装成扩展的 `chrome_url_overrides.newtab`）。

## 功能

### 时钟与搜索
- 实时时钟（时:分 + 秒）、按时段变化的问候语、当日日期。
- 搜索引擎可切换：Google（默认）、Baidu；回车在当前标签页跳转搜索。
- 下拉菜单选项被卡片遮挡的问题已修复（层级 + 最大高度滚动）。

### 常用网站面板
- 独立圆角卡片，顶部为分页标签，支持：
  - 点击分页标签、左右箭头、`Shift + 滚轮`、左右横向滑动（> 70px 视为翻页）切换。
  - 分页标签可拖拽调整顺序。
  - 分页的新增 / 重命名 / 删除 / 排序在「设置 → 分页管理」中完成，至少保留一页。
- 网站图标下方显示名称（两行内截断），图标本身用名称首字母色块占位。
- 一个网站可配置多个链接（例如 DeepSeek 的 `Chat` 和 `Platform`）：
  - 单链接：点击图标直接打开。
  - 多链接：点击图标弹出标签菜单，选择后打开；图标右下角显示链接数量。
- 文件夹可无限嵌套，单页内显示面包屑可逐级回退，文件夹内操作逻辑与分页一致，并显示内部条目数量角标。

### 统一右键菜单（触屏长按 520ms）
- 网站图标：打开、编辑、删除、移动到…、复制到…
- 文件夹：打开、重命名、删除、移动到…、复制到…
- 空白处：新增网站、新增文件夹
- 分页标签：重命名分页、删除分页
- 「移动到… / 复制到…」打开分页 + 文件夹的树形选择框；移动时禁止放入自身或子级文件夹；复制文件夹会连同内部内容一起复制。
- 所有删除操作都有二次确认。

### 拖拽
- 图标在当前分页/文件夹内拖动排序，其他图标实时让位。
- 拖到文件夹上可移入，拖到其他分页标签可移动到该页。
- 拖动以鼠标为主，触屏以长按菜单为主。

### 主题与外观
- 仅黑白两套主题：浅色（默认）、深色；设置中浅色在前。
- 无彩色强调色，选中、焦点、悬停、危险操作均为灰度反馈。
- 全页文字不可选中（输入框内仍可正常编辑）。
- 支持 `prefers-reduced-motion` 降级，键盘可达、焦点可见。

### 导入 / 导出
- 设置 → 导出备份：下载 JSON 文件，文件名形如 `WayMarkTag-<YYYYMMDDhhmmss>-<4位随机>.json`（例：`WayMarkTag-20261108001118-a3k9.json`）。
- 设置 → 导入备份：读取 JSON 后校验、二次确认，成功则整体替换当前数据。
- 数据同时写入 `localStorage`，刷新不丢。

## 导出数据结构

`localStorage` 键：`waymarktag-start.v1`

```json
{
  "app": "waymarktag-start",
  "version": 3,
  "exportedAt": "2026-11-07T00:00:00.000Z",
  "theme": "light",
  "engine": "google",
  "pages": [
    {
      "id": "page-daily",
      "name": "日常",
      "items": [
        { "id": "site-a", "type": "site", "name": "DeepSeek",
          "links": [
            { "label": "Chat", "url": "https://chat.deepseek.com" },
            { "label": "Platform", "url": "https://platform.deepseek.com" }
          ]
        },
        { "id": "folder-a", "type": "folder", "name": "开发",
          "items": [ { "id": "site-b", "type": "site", "name": "MDN", "links": [ { "url": "https://developer.mozilla.org" } ] } ]
        }
      ]
    }
  ]
}
```

- `theme`：`light` | `dark`
- `engine`：`google` | `baidu`
- 节点 `type`：`site` | `folder`
- `site.links`：至少一条，`label` 可空（单链接时不显示标签菜单）
- 导入时会做结构清洗（`sanitize`）、去重 id、修正非法颜色/引擎，并兼容旧版本数据（旧 `url` 字段会迁移为单链接，旧的扁平快捷方式会迁移为单页）。

## 默认内容

- 分页「日常」：DeepSeek（Chat / Platform）、GitHub、知乎、哔哩哔哩、少数派、豆瓣、Figma、Notion
- 分页「工作」：文件夹「开发」（MDN、Stack Overflow、文件夹「前端」→ Can I use、CSS-Tricks）、GitHub、Linear、Slack

## 已知限制

- 图标为名称首字母色块占位，暂不支持上传真实 favicon / 图片。
- 纯静态页面，未包含 `manifest.json`，不能直接以「加载已解压的扩展程序」方式安装；当作扩展使用需要补 manifest 并把新标签页指向该页面。
- 数据仅保存在当前浏览器（`localStorage`），换浏览器或清缓存需用导出文件恢复。
- 网站/搜索链接在新标签页打开，可能被浏览器弹窗策略拦截，需要允许。
- 拖拽排序以桌面端为主；移动端建议使用长按菜单。
